To run Alizarin, you need [Arches](https://github.com/archesproject/arches) JSON,
which can be generated with Arches or, in pure Python, with [AORM](https://github.com/flaxandteal/arches-orm).

Alizarin can run via static JSON files, or from an Arches-compatible API.

It needs, unless precached, JSON endpoints for collections, concepts, resources (tiles) and graphs.

## Quick Start

After `npm install alizarin` (see [Installation](/docs/installation)), point the
shared `graphManager` singleton at a client, initialise it, then load and query
models.

### Basic Usage

```typescript
import { client, graphManager, staticStore, RDM } from 'alizarin';

// Point the shared graphManager (and the stores it uses) at an Arches instance
const archesClient = new client.ArchesClientRemote('https://your-arches-instance.org');
graphManager.archesClient = archesClient;
staticStore.archesClient = archesClient;
RDM.archesClient = archesClient;
await graphManager.initialize();

// Load a resource model
const MonumentModel = await graphManager.get('Monument');

// Query all monuments
const monuments = await MonumentModel.all();

// Access data through transparent, lazily-hydrated property access
for (const monument of monuments) {
  console.log(await monument.name);
  console.log(await monument.constructionDate);
}
```

### Working with Static Data

```typescript
import { client, graphManager, staticStore, RDM } from 'alizarin';

// The same flow, but reading pre-exported static JSON (no live server needed)
const archesClient = new client.ArchesClientRemoteStatic('/data/exports');
graphManager.archesClient = archesClient;
staticStore.archesClient = archesClient;
RDM.archesClient = archesClient;
await graphManager.initialize();

// Usage is identical to the remote client
const PersonModel = await graphManager.get('Person');
```

### Querying Resources

```typescript
const PersonModel = await graphManager.get('Person');

// Query all people
const people = await PersonModel.all();

// Access data through view models
for (const person of people) {
  console.log(await person.forename);
  console.log(await person.surname);
}
```
