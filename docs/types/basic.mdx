The basic scalar view models wrap primitive-like Arches datatypes. They resolve
to a value you can render directly — with one caveat below.

## string

`StringViewModel` wraps a localized `string`. It **extends `String`**, so it
stringifies to the value in the [current language](/docs/types/i18n) and can be
rendered directly in JSX. `non-localized-string` (`NonLocalizedStringViewModel`)
is the single-language variant.

## number

`NumberViewModel` wraps a numeric value. Like the other non-string scalars it is
an object, not a primitive — coerce it (`` `${value}` `` or `String(value)`)
before rendering, or React will reject a raw `Number`/`Date` object as a child.

## boolean & url

`BooleanViewModel` wraps `true`/`false`; `UrlViewModel` wraps a URL string.
